# Code of conduct

Keep project activity technical and on topic.

Do not threaten, harass, publish private information, spam, impersonate, sabotage, or deliberately disrupt project work.

Technical disagreement, criticism, rejected contributions, and forks are allowed.

The maintainer may remove disruptive content or restrict disruptive accounts.

Report a problem privately through a [GitHub security advisory](https://github.com/bgrablin/hermes-windows-bridge/security/advisories/new). Prefix the title with `[Code of Conduct]`.
