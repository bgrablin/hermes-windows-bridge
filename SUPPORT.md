# Support

## Usage questions

Read the [README](README.md), [operations guide](docs/operations.md), and [security model](docs/security-model.md) first. If the answer is not there, open a **Help or usage question** issue.

Include the release tag or commit, controller operating system, Windows version, Python version, and a minimal reproduction. Redact tokens, private keys, certificates, hostnames, network addresses, private paths, command output, and other operational data.

This project does not provide managed deployment, emergency response, or a support SLA.

## Bugs and feature requests

Use the structured bug or feature issue form. Search for an existing issue first. Substantial security-boundary or compatibility changes should be discussed before implementation.

## Security and conduct reports

Report vulnerabilities through a private [GitHub security advisory](https://github.com/bgrablin/hermes-windows-bridge/security/advisories/new). Follow [SECURITY.md](SECURITY.md).

Use the same private advisory channel for confidential Code of Conduct reports and prefix the title with `[Code of Conduct]`. Do not post confidential details publicly.
